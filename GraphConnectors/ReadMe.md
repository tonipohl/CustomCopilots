# Graph Connectors

Microsoft 365 Copilot helps users discover and work with relevant information available across Microsoft 365. To make content from external data sources available to Microsoft 365 Copilot and Microsoft Search, you can use Microsoft Graph connectors.

A custom Microsoft Graph connector retrieves content from an external data source and ingests it into Microsoft 365 through the Microsoft Graph API. Microsoft Entra ID is used to authenticate and authorize access to Microsoft 365.

For an introduction to Microsoft Graph connectors, see [Microsoft Graph connectors–Introduction](https://learn.microsoft.com/en-us/training/modules/copilot-graph-connectors/1-introduction?WT.mc_id=AZ-MVP-5000174).

This repository provides PowerShell scripts to create a custom Microsoft Graph connector and ingest sample data.

To run the scripts, you need the required Microsoft 365 administrative permissions and a Microsoft Entra ID app registration. For information about registering an application in Microsoft Entra ID, see [Register an app in Microsoft Entra ID](https://learn.microsoft.com/en-us/power-apps/developer/data-platform/walkthrough-register-app-azure-active-directory?WT.mc_id=AZ-MVP-5000174).
